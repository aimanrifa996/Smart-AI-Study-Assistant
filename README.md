# Smart AI Study Assistant

## Overview
Smart AI Study Assistant is a Python-based application powered by Google Gemini AI. It helps students learn concepts, summarize notes, generate quizzes, and understand programming topics through an interactive interface.

## Features
- **AI Chat Assistant:** Ask questions and receive AI-generated answers.
- **Explain Concepts:** Understand topics at beginner, intermediate, and advanced levels.
- **Notes Summarizer:** Convert lengthy notes into concise summaries.
- **Quiz Generator:** Generate multiple-choice quizzes and check your answers.
- **Coding Assistant:** Get help with programming concepts and code.

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- Google GenAI
- Python-dotenv

## Installation and Setup

1. Clone or download this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Create a `.env` file in the project directory.
4. Add your Gemini API key:

   `GEMINI_API_KEY=your_api_key_here`

5. Run the application:

   `python -m streamlit run ai_application.py`

## Security
Keep your API key private. Never upload your `.env` file or expose your API key publicly.

## Purpose
This project demonstrates how AI tools and APIs can be integrated into a practical application to improve learning and productivity.
